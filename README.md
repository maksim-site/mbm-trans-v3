# МБМ-Транс — версия 3

Готовая статическая версия сайта `mbm-trans.ru` с одним same-origin
PHP-обработчиком заявок. Сайт рассчитан на размещение у российского хостинг-
провайдера; персональные данные формы не отправляются в Cloudflare, Telegram,
Google или другие внешние API.

## Локальный просмотр

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

На этом сервере форма работает только в безопасном режиме предпросмотра и не
отправляет введённые данные. PHP запускается только после размещения на хостинге.

## Что переносить на боевой хостинг

Загружать нужно только:

- `index.html`;
- страницы `*.html` из корня;
- папку `assets/`;
- папку `api/leads/`;
- `favicon.ico`, `robots.txt`, `sitemap.xml`.

Не загружать: `.git/`, `.design-director/`, `old-site-backup-*`, архивы `*.zip`,
`cloudflare/`, `build_pages.py`, `modx-preview-mbm-2026/`, `screenshots-v2/`,
`tmp/`, `tools/`, `telegram-*.php`, `telegram-config.example.php` и
`mbm-lead-mail.php`. Эти файлы сохранены только для истории и локальной работы.

## Заявки

Формы отправляют `POST` на `/api/leads/`. Обработчик:

- принимает запросы только с того же сайта;
- валидирует имя, телефон, e-mail и согласие;
- использует honeypot и проверку времени заполнения;
- не делает внешних HTTP-запросов и не сохраняет заявки в файлах;
- передаёт письмо локальной почтовой системе российского хостинга через `mail()`.

Перед публикацией в панели хостинга задать:

- `MBM_LEAD_RECIPIENT` — адрес получателя, по умолчанию `info@mbm-trans.ru`;
- `MBM_LEAD_FROM` — адрес отправителя на домене сайта, рекомендуется
  `site@mbm-trans.ru`.

Хостинг и почтовый сервер получателя должны находиться в России. На сервере
должны быть PHP 8.0+ и настроенная отправка почты с домена `mbm-trans.ru`.

## Проверка перед переключением домена

1. Сохранить текущий сайт и базу данных отдельной резервной копией.
2. Развернуть эту версию на временном российском поддомене с HTTPS.
3. Проверить главную, четыре услуги, проекты и политику на телефоне и компьютере.
4. Отправить тестовую заявку и убедиться, что письмо пришло без попадания в спам.
5. Проверить адрес отправителя, SPF, DKIM и DMARC в панели почты.
6. Убедиться, что `/api/leads/` отвечает `405` на `GET` и принимает только `POST`.
7. Переключить домен, включить автоматический сертификат и повторить проверку.
8. Старую версию не удалять до окончания контрольного периода.

## Важное

Папка `cloudflare/` — только архив прежнего эксперимента. Она не используется
активными страницами и не должна попадать на боевой сервер.

Файл `build_pages.py` — устаревший генератор предыдущего дизайна. Его нельзя
запускать поверх актуальных HTML-файлов.
