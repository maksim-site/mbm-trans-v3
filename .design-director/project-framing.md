# Project framing

## Selected site model

- Model: Corporate multipage.
- Decision source: explicit user clarification.
- Why: задача — заметно улучшить существующий сайт, не превращая редизайн в дорогое производство большого количества новых кейсов, видео и 3D-материалов.

## Information architecture

- Page topology: Home; About; 4 current service pages; Projects; Clients; Contacts; Privacy.
- Primary conversion path: главная/страница услуги → реальные доказательства → «Рассчитать перевозку» → same-origin форма.
- Navigation model: привычная горизонтальная навигация на desktop; компактный drawer на mobile; один постоянный primary CTA.
- Content depth: сохранить текущий SEO-контент, сократить визуально тяжёлые фрагменты и повысить сканируемость.
- SEO or catalog implications: сохранить существующие публичные URL; при любом переименовании создавать точные `301` redirects.
- Main trade-off: без новых больших медиаматериалов выразительность должна строиться на сетке, типографике, image treatment и одной содержательной interaction, а не на количестве эффектов.

## Optional future expansion

- Отдельный шаблон детального кейса можно добавить позже.
- Текущий редизайн не зависит от готовности 6–12 полноценных кейсов.
- Существующая страница проектов остаётся полноценной proof surface.
