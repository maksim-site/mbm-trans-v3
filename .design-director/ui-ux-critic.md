# Preliminary UI/UX critic

## Source

- Skill: `ui-ux-pro-max`.
- Query: corporate industrial logistics B2B professional trustworthy expressive motion.
- Status: preliminary; final `ux-foundation.md` will be created after experience and reference selection.

## Useful recommendations

- Base character: Trust & Authority rather than generic tech or playful logistics.
- Keep credentials, clients, certificates and project evidence visible.
- Use one primary CTA wording across pages: «Рассчитать перевозку».
- Preserve familiar navigation; no mega menu is needed for the current scope.
- Body text should remain at least 16 px on mobile, with 1.5–1.75 line height and controlled line length.
- Interactive targets should be at least 44 × 44 px and have visible keyboard focus.
- Micro-interactions should normally stay within 150–300 ms.
- Project micro-video must be click/tap accessible, paused off-screen and never the only way to receive information.
- Use no more than 1–2 animated elements per viewport.
- Reserve media dimensions to prevent layout shift.
- Test at 375, 768, 1024 and 1440 px.

## Visual-system implications

- Keep navy as an identity anchor but move away from the current flat blue overlay.
- Explore steel, asphalt, off-white and warm safety-orange as functional roles rather than decorative stripes.
- Test both a restrained light system and a dark photographic system at the style-selection stage.
- Prefer self-hosted Lexend + Source Sans 3, or another Cyrillic-capable open-source pair, with no Google Fonts runtime calls.
- Do not introduce glassmorphism, purple gradients, oversized pills or generic bento-card repetition.

## Current-site priorities

1. Make the hero CTA and proof hierarchy clearer.
2. Reduce repeated card grammar and decorative hazard stripes.
3. Improve the scan rhythm of long sections.
4. Make projects and real machinery visually dominant.
5. Make the form shorter to understand, with clear success/error states.
6. Keep the mobile header, navigation and phone action obvious.
7. Replace foreign runtime dependencies and document the Russian data path.
